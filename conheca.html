Perguntas frequentes

A cliente precisa baixar algum aplicativo?

Não. Ela abre o seu link no navegador do celular, escolhe o horário e informa nome e WhatsApp. Se quiser, pode criar uma conta para ver os horários em qualquer aparelho.

As mensagens saem do meu WhatsApp?

Saem do WhatsApp do AgendaPro, pela API oficial da Meta, com o nome do seu salão no texto. Você não precisa deixar o celular ligado nem mandar nada à mão. Cada plano tem uma franquia de mensagens por mês.

Serve para quem trabalha sem equipe?

Sim, o Essencial é para um profissional. Quando a equipe crescer, você muda de plano sem perder nada do que já cadastrou.

Funciona no celular e no computador?

Nos dois, pelo navegador. No celular dá para instalar na tela inicial e abrir como aplicativo.

Quanto tempo leva para começar?

Dá para começar hoje. O passo a passo do primeiro dia leva você do cadastro até o link pronto para mandar.

Quais são as formas de pagamento?

Pix, cartão de crédito (renova sozinho todo mês) ou boleto, pelo Mercado Pago. Sem fidelidade e sem multa.

Tem suporte?

Tem, direto pelo WhatsApp — de dentro do painel ou pelo botão aqui embaixo.

Meus dados e os das minhas clientes ficam seguros?

Cada salão só enxerga os próprios dados, e quem trabalha com você só vê o que a função dela permite. Se um dia quiser sair, você mesmo exclui a conta pelo painel.
